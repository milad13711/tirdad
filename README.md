# تیرداد — لندینگ پیج پلتفرم آموزش، هوش مصنوعی و رشد اینستاگرام

لندینگ پیج فارسی (RTL) برای پلتفرمی که دوره‌های آموزشی، ابزارهای تولید محتوا با هوش
مصنوعی، بسته‌های پرامپت و CRM اینستاگرام را ارائه می‌دهد. سبک بصری (پس‌زمینه تیره،
اکسنت آبی، تایپوگرافی جسورانه، انیمیشن‌های اسکرول) از سایت نمونه
[majidtirdad/majidtirdadsite](https://github.com/majidtirdad/majidtirdadsite) الهام
گرفته شده است.

این مرحله فقط شامل **UI لندینگ پیج** است (بدون بک‌اند واقعی) — با محتوای نمونه برای
بخش‌های خدمات، دوره‌ها، ابزارهای AI، پلن‌های اشتراک، نظرات مشتریان، CRM اینستاگرام،
سوالات متداول و بلاگ.

## استک فنی

- Next.js 16 (App Router)
- TailwindCSS v4
- shadcn/ui-style primitives روی Radix UI
- next-themes برای حالت تاریک/روشن
- framer-motion برای انیمیشن‌های اسکرول
- فونت Vazirmatn برای پشتیبانی کامل فارسی/RTL

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس [http://localhost:3000](http://localhost:3000) را باز کنید.

## بیلد

```bash
npm run build
npm run start
```
